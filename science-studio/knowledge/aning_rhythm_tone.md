## 3. 语气（主持 vs 大肥鱼）
- **主持（阿柠）**：讲解腔+口语，整体快而平，不表演；重音落在**对比词和数字**；否决句「其实还真不是。」放慢、单独成行；夸人句「大肥鱼，这个问题你问得好」暖，紧接机制，不停顿。口语填充少，常用「其实」「简单来说」「那」「所以」。
- **大肥鱼**：只说短句（8–18 字），**开头必带语气词**「哼，」「嗯？」；内容=观众的错误直觉/下一章疑问；语调上挑、略嘴硬，从不讲解。
- **接话**：问→答 停顿 ≈0.2 s，几乎咬尾；主持接住先 5–12 字短答再展开；没有“等对方说完再沉默”的空拍。
- 转场咒语：「这时候你可能会这么想。」→ 鱼错直觉 → 否决锤 → 机制 → 比喻。

## 4. trial_open_v1 的主要差距
1. **慢**：4.1 vs 6.5 字/s（慢 37%），鱼慢一半（3.4）。
2. **停顿太长且均匀**：0.38 s 均匀 + BGM 抽空/空镜，阿柠是 0.22 s 且无 >0.6 s 空白。
3. **BGM**：happy_arcade_tune −17 dB + 重 sidechain → 应换阿柠同款（或分离参考）且人声下 −14 LU 平铺、不抽。
4. **语气**：O 平念、鱼像念台词；缺「哼/嗯？」开头、缺否决锤慢半拍、缺数字/对比重音。
5. **戏剧节拍**：缺「这时候你可能会想」→鱼错直觉→「其实还真不是」三连，鱼只在开头抢话。
