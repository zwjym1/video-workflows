## 四、规律

**【数据】**
1. **知识讲解期远超剧情和日常期**。3 条讲解期的抖音赞是 2845–33169；3 条剧情和日常期只有 31–345。
2. **讲解期是典型的收藏型内容**。收藏数和点赞数的比值：MCP 0.73、Skill 0.72、Harness 0.54；日常期只有约 0.10。
3. **最火的一期是最老的题**。MCP 在全网爆发约 19 个月后，B站同题 64% 都超过半年。最新的 Skill、Token 反而最弱。
4. **平台反差**。讲解期在 B站只有 36–239 播放；剧情期《谢谢你，大肥鱼》在 B站 28098 播放，在抖音只有 92 赞。
5. **标题有固定模板**：「系列名 Vibe知识大赏 \| X是什么？一个视频讲清楚」。最火的 MCP 期是例外，它没用术语，写的是收益问句「如何让AI用电脑里的软件帮你打工？」，开头 3 秒就展示 DeepSeek 调用 PS 换背景（据 qoder 拆片）。
6. **节奏**：10-28、10-29、10-30 连续三天日更讲解期，11-01 接着发 Token；每期 4–6 分钟，一期只讲一个概念。

**【推断】**
- **选题类型**：她选的是 Agent 生态的「圈内热词」（Harness / Skill / MCP / Token），属于新概念或老概念，不做新工具测评，也不做实操教程。据拆片，MCP 期没有安装和配置画面。
- **入场时机**：她不抢首发，入场时间在热词首次爆发后 2 周到 19 个月不等。真正决定成绩的不是新不新，而是这个词有没有渗透到「用过 DeepSeek 但不懂术语」的大众，加上开头有没有能直接看见的收益（AI 帮你操作 PS）。老题配上新角度（收益问句 + 一整套类比 + 反常识「工具不是越多越好」），能打败新题。
- **哪类火、哪类不火**：讲解期里，有画面化收益的概念（MCP=给 AI 装手）最火；纯抽象的概念（Skill）弱；剧情和日常在抖音不火，但在 B站有情感共鸣的受众。
- **难度层级**：她做的是 L2，也就是「用过 AI、听过术语的人」。Harness 期最高赞评论说「小白一脸懵」，说明零基础的人跟不上。这正好是我们的空档：我们的受众是 L0/L1 零基础。
- **标题写法**：「是什么 + 一个视频讲清楚」是稳定的系列模板；能爆的写法是**不写术语，写收益**的问句。B站换成了「为什么……差距这么大」这种疑问句，但她 B站账号太小（374 粉），没法判断标题的效果。
- **可能的混淆因素**：MCP 期能爆，也可能和「账号刚被推荐」或者前一期 Harness 带来的涨粉有关。只有 6–7 条样本，规律需要后续几期验证。

## 五、我们该学什么 / 不学什么【推断】
- **要学**：
  1. 每题必须有一个当场能看见的收益或反常识的「哇点」，没有就不做。
  2. 标题写收益问句，不写术语。
  3. 一期只讲一件事，配一整套贯穿全片的日常类比。
  4. 老题可以做，前提是有新角度，不必追首发。
  5. 用固定系列名加固定栏目模板，方便日更。
- **不学**：她停在 L2 概念层，评论已经有小白说听懵。我们坚持「当场照做一件事」的 L0 定位，在她的概念上往下做一层实操版（例如把「MCP=给AI装手」做成「让豆包帮你改一张图」），把她的受众吸引过来，而不是跟她拼概念讲解。
- **注意**：她也用「大肥鱼」做角色，签名自称「大肥鱼fans」，和我们的角色同名，需要做出区隔。
