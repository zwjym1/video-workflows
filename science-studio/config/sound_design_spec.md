# Sound Design 规范 v1（2026-10-21，EP-20261021-02 r7 起，所有片通用）

参考做法（2026-10-21 快速调研）：
- Kurzgesagt 每期都有原创配乐，音效只做「不抢戏的附加层」。
- Motion graphics 圈的通行做法：
  - 一期只用一个音色家族，10–20 个可复用音，映射到固定动作（arrive/glide/lock/burst…）。
  - 同一空间（混响一致）。
  - 带音高的音效与配乐/氛围同调。
  - 重复音每次错开 2–3 个半音，或沿音阶递进。
  - pop 落在定格帧，whoosh 提前约 100 ms。
  - 闪避人声。
- 行业电平口径：
  - 氛围比人声低 10–15 dB。
  - whoosh/riser 比人声低 6–10 dB。
  - 冲击可短暂接近人声。
  - 成片 web 母带：真峰 ≤ −1 dBTP。
- 来源：
  - showtime sound-design 文档
  - CinematicSFX 电平指南
  - SonusGearFlow 文章
  - Cursa 2D motion 课程
  - Kurzgesagt 官方 What we do / How to make a Kurzgesagt video

## 1. 先定风格（每期开工前写进 STATE）
- 每期只选一个风格家族，在汇报里写明。默认「轻科幻 + 卡通拟人」：
  - 干净的卡通/UI 质感：柔和 pop、whoosh、soft impact、玻璃 chime、低频 sub hit。
  - 拟人段落可以更俏皮，但不能出这个家族。
- 备选家族（整期统一，不混用）：
  - 纪实/严肃：tick、thock、低 chime、氛围、少量 sub。
  - 网感梗音：只用于整期都是梗风的片。

## 2. 音色家族清单（默认家族；实现在 /workspace/science-studio/lib/sound_palette_v1.py）
| 代号 | 音色 | 构成 |
|---|---|---|
| SUB | 柔和低频冲击 | 正弦从 2.2×f0 滑到 f0（A1=55 Hz），加 12 ms 低通噪声起音，tanh 软饱和 |
| BITE | 拟人咬合「啊呜」 | SUB，加下滑 chomp 音，加牙齿 tick；连续多口按五声音阶逐级升调 |
| THOCK | 中频软击 | 220 Hz 下滑，加 900–3.5k 噪声短起音 |
| POP | 卡通 pop | 上滑短正弦，音高取 A 大调五声 |
| TICK | UI 轻点 | 高八度五声正弦 12 ms 衰减，加高通噪声 |
| CHIME | 玻璃铃 | 1/2/3/4.2 次谐波，双音时为五度上行 |
| RISE | 上扬 | 带通扫频噪声，加 A3→A4 滑音，末端 30 ms 收 |
| WH | whoosh | 固定两条：Mixkit #166（短）、#1490（长）；只做变速，不换素材 |
| BED | 氛围底 | 布朗噪声低通 180 Hz，加 55/82.5 Hz（A/E）慢颤 |

调性：所有带音高的音效都在 A 大调五声（A B C# E F#）内，与氛围底的 A/E 同调。

## 3. 动作 → 音效类别映射
| 画面动作 | 类别 |
|---|---|
| 首帧冲击、大字砸下、关键反转/设问 | SUB（设问用长尾版，tau 0.5 s） |
| 角色咬/吞/撞（拟人） | BITE |
| 被拍、被扯、盖章、打孔重击 | THOCK |
| 元素弹出（柱子、气泡、框、卡片） | POP；序列按音阶上行 |
| 打字、打孔、时间轴点亮、相机/锁定 | TICK；序列按音阶上行 |
| 结论成立、计数完成、「叮」 | CHIME |
| 拉伸、蓄力、撕裂前 | RISE（结尾对准落点） |
| 推拉镜、转场、快速移动 | WH（远距离/换场用长条，短移动用短条） |
| 心跳 | SUB 短版，两下间隔 0.2 s |

## 4. 电平：每类固定目标，自动归一，不逐个手调
- 测量口径：
  - 每个音效先统一处理（见 §5）。
  - 再测 K 加权（BS.1770）150 ms 窗的峰值电平。不对短音效用 loudnorm，因为 BS.1770 门限对短于 400 ms 的片段不可靠。
- 人声参考 Rv：纯人声 150 ms K 加权电平在语音段的第 90 百分位。
- 每类目标（相对 Rv，空档时）：
  | 类别 | 目标 |
  |---|---|
  | BITE | −3 dB |
  | SUB | −6 dB |
  | THOCK | −8 dB |
  | POP | −9 dB |
  | WH | −10 dB |
  | RISE | −11 dB |
  | CHIME | −11 dB |
  | TICK | −13 dB |
  | BED | 积分响度 = 人声 − 20 LU |
- 人声闪避：有语音时全部 SFX 自动 −4 dB（攻 30 ms / 释 250 ms）。
- 允许范围：
  - 同类事件之间只允许闪避造成的 4 dB 差。
  - 全部音效落在 Rv −3 至 −17 dB 之间（最大差 14 dB）。
  - 超出即算违规。
- 母带：
  - 积分 −16 LUFS（±0.5）。
  - 4× 过采样限幅，真峰 ≤ −1.5 dBTP（规范红线 −1）。
  - LRA ≤ 4 LU。
  - 末尾 0.4 s 淡出。

## 5. 统一处理链（每个音效都过同一条）
1. 高通：SUB/BITE 30 Hz，其余 70 Hz。TICK/CHIME/POP 再高通 140 Hz 去浑浊。
2. 低通 9 kHz（4 阶），去刺耳高频。
3. 2.5–5 kHz 带内约 −2.5 dB，去刺。
4. 同一个短房间：0.35 s 指数衰减噪声 IR，湿声 0.18，所有音效共用，像在同一空间。
5. 按 §4 归一后，再按时间点放入。

## 6. 密度规则
- 用户接受「密集」，但每个音必须对应一个画面事件。
- 同时最多 2 层：whoosh + 落点。
- 序列（打字、柱子、时间轴）用同一音沿音阶走，不换音色。
- 关键反转前留 0.25–0.5 s 相对安静。

## 7. 禁用项
- 跨家族的梗音：
  - vine boom、metal pipe、taco bell bong、anime wow、shocking
  - 罐头笑声、游戏 coin/power-up
  - 例外：整期定为「网感梗音」家族时可以用。
- 严肃电影音效与卡通音混用：cinematic braam、悬疑 sting、真实拳击/耳光。
- 每个音效逐个手调音量。必须按类别目标自动归一。
- 不同混响/空间的素材直接混用。
- 超出调性的带音高音效。

## 8. 交付
- 混音脚本要能在 box 和 PC 两端运行，同一份输出：`python sound_palette_v1.py <纯人声wav> <mixkit目录> <输出目录>`。
- 每次同时导出 `sfx_only.wav`（音效+氛围，按成片电平，无人声）供单听。
- 只换音轨时不重渲画面：`ffmpeg -c:v copy` 替换音轨，并核对视频流 MD5 不变。

## 9. 用户偏好（2026-10-21 r7→r8 反馈，优先于上文默认家族）
- 基调用「网感梗音」（r6 的 myinstants 风格）。用户评价 r6「其实不错，很有网感」，否掉了 r7 的纯自制家族。
- 网感梗音里，也要去掉三类：
  - 与场景不搭的：例如「恒星外层被扯成面条」配巴掌声。
  - 起伏/转变太大的：例如突然的悬疑 sting、金属管碎裂。
  - 像吹喇叭/号角的：铜管类谐波、持续音高。
- 同一个不讨喜的音效不要在全片重复。替换时每个点换成不同的音。
- 替换音的电平取周边 ±12 s 内 r6 音效的中位电平（K 加权 150 ms），不能忽高忽低。
- 禁用清单（本片被否）：
  - sudden-suspense-sound-effect
  - shocking_0NL2w3I
  - slap-soundmaster13（不能用于拉扯场景）
  - metal-pipe-clang
  - taco-bell-bong-sfx（吹喇叭感；本片用户选择保留）
  - anime-wow-sound-effect（吹喇叭感；本片用户选择保留）
  - r7 自制合成家族（整体不要）
