# 交付与发布检查清单
每一期复制后填写实际状态；空项不能靠“技术通过”代签。

## 三个用户门
- [ ] 同题原片/文案/真实评论与缺口已记；核心主张来源已核
- [ ] 门一：完整口播和逐段演法、真实选图/梗图手机拼板、自然句术语试听一起确认
- [ ] 显示/朗读文本分离；实际听过型号数位、Ti/tai、BIOS自然读法，不能用ASR替代
- [ ] 门二：连续带声代表段有完整因果，确认后才扩全片
- [ ] 门三：完整片及完整发布包交用户终审；改动先审局部加前后上下文

## 画面与声音
- [ ] 对象身份与来源持续，因果/答案不提前，结果保留再交接
- [ ] 停用单元留原位且手机可辨；不复绿暗示开核成功；假设不是某产品制造实证
- [ ] 实物素材高清、美观、轮廓完整；晶圆不裁边、不用支架遮挡照凑数
- [ ] 主体精致、留白清楚、单焦点；真实图到简图衔接，不叠密集说明
- [ ] 标题/旧标题/型号/图片/字幕全布局避撞，转场编码帧与360手机图已实查
- [ ] 字幕无标点、自然短句单行、统一字号、安全边界真实bbox逐条测
- [ ] 音轨finite、逐秒min/max/mean/std/RMS、无异常DC；编码前平方根负舍入已钳位
- [ ] 原音不变时AAC码流复制且payload hash相同；读法修改重生整句并听接缝
- [ ] 解码、黑场、帧率/帧数/时长、响度/峰值、开头和最后尾音已核
- [ ] 视觉/听感实际审看，机检通过未冒充效果/算法保证

## 素材与平台
- [ ] 每个asset_id有原页URL/作者/实际许可/哈希/拟用裁切及确认状态
- [ ] 梗图原字、粗俗表达、刀具/不适宜画面、肖像与声音权利已筛，不编授权
- [ ] 平台拒绝原提示已留档；无时间点不猜原因；删除范围经确认后再检测
- [ ] 平台复测状态如实：未测/待结果/通过/未通过，未通过不写已通过

## 齐套交付：漏封面即未完成
- [ ] 最终1080全片及明确版本名（旧版保留）
- [ ] 竖3:4封面1080×1440 PNG/JPG，实际打开检查
- [ ] 横4:3封面1440×1080 PNG/JPG，实际打开检查
- [ ] 封面并排手机预览，型号与照片不混，不贴未核价格或认证章
- [ ] 主标题1个、备用1个、封面字、正文、话题、需要时置顶评论
- [ ] 字幕SRT/时序、必要源文件、技术QC、来源与许可/事实待核记录
- [ ] 全片与修改合集、清单中的路径都可读，文件尺寸正确，未交付项显式标红/未完成
- [ ] 电脑目标与交付状态记私有附录；目录范围被拒即停止，不绕过、不假报落盘
- [ ] 未获明确代发指令不上传或发布；平台确认与实际发布登记分开

## 归档边界
- [ ] GitHub仅规则/脚本/模板；无keys、cookies、token、凭据、模型权重、成片/第三方素材原件
- [ ] 私有机器路径、账号、联系人和本案操作日志不进入公版模板/公版zip
- [ ] 新版有CHANGELOG，历史失败版本与已废止规则不作默认
