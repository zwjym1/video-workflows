# V3f 称呼与来源处理：调研结论 + 口播改句对照

调研时间：2026-10-18 23:45–00:00（UTC+8）。只用了公开网页，没有登录抖音。

## 一、国内规定（原文摘录）

1. 《互联网新闻信息服务管理规定》第十五条：
   「互联网新闻信息服务提供者转载新闻信息，应当转载中央新闻单位或省、自治区、直辖市直属新闻单位等国家规定范围内的单位发布的新闻信息，注明新闻信息来源、原作者、原标题、编辑真实姓名等……并保证新闻信息来源可追溯。」
   - 链接：https://www.cac.gov.cn/2017-05/02/c_1120902760.htm
   - 推断：个人号没有新闻资质，转载规则管的是「转载新闻」。如果画面上挂着「BBC / 某外媒」的角标、标题页，看起来就像在转载境外新闻。去掉角标和外媒报道页，改成自己的核查讲解，这样更稳。
2. 《网络信息内容生态治理规定》第七条（不良信息）：
   「（一）使用夸张标题，内容与标题严重不符的；……（三）不当评述自然灾害、重大事故等灾难的；……（五）展现血腥、惊悚、残忍等致人身心不适的」
   - 链接：https://www.cac.gov.cn/2019-12/20/c_1578375159509309.htm
   - 对应改动：
     - 04 句「沉了」改成「是真的」。
     - 冒烟大船、人群哄抢的镜头，改成漂浮集装箱、平静海面的近景。
     - 弹幕只留好奇类。
3. 抖音《内容标识使用规范》官方问答（2023-09-08 起实施）：
   - 「发布国内外时事、公共政策、社会事件的相关内容……属于引用他人所发布内容的，需添加引用来源……如引用非抖音平台内容，需选择『站外』的标识。」
   - 「人工智能生成内容……包括但不限于：AI 合成的真人视频……」需要添加标识。
   - 链接：https://news.qq.com/rain/a/20230908A05JJZ00
   - 对应做法：来源不写在画面上，用发布时的「内容标识 → 引用来源 → 站外」来交代。
4. 抖音「搬运」认定（中国新闻出版广电报转载）：
   「……截掉或者用贴纸挡住平台的 LOGO 发布；搬运……外网视频片段，并且只进行简单的二次创作的内容……出现抖音平台之外的水印特效等元素。」
   - 抖音短剧版权中心公告（2026-03-13）还提到：「素材画面中带有他人水印号或利用马赛克等方式遮挡他人水印」。
   - 链接：
     - http://www.hljcopyright.com/html/zcfg/xydt/1578.html
     - https://m.thepaper.cn/newsDetail_forward_32767365
   - 结论：
     - 画面里留着他台水印会被判搬运。只遮水印、不加实质内容，同样算搬运。
     - 本片每个外来镜头都配了我们自己的讲解，以及圈注、对比、检测卡。外来素材只占单镜一部分，平台标识做裁切或局部模糊。
     - 这属于「评论/核查」类二创，不是简单搬运。这一条是推断，以平台实际判定为准。
5. 《抖音社区热点信息和账号治理规则（试行）》（2025-05-27）：
   「对新闻要素不全、无权威信源等热点内容纳入『存疑』热点持续追踪。」
   - 链接：https://www.jjckb.cn/20250527/647e46fa86cf485fa542e9b3b84d188a/c.html
   - 对应做法：简介里写清「核查依据为公开报道和检测工具」，不渲染事件本身。

## 二、同类账号和主流媒体怎么称呼

- **央视新闻**（央广网转载，2026-03-21，多段美以伊视频被证伪）用的说法有：「一张图片在海外社交媒体平台流传」「经核查，该视频为人工智能生成内容」「使用图像鉴定工具对网传图片进行分析后发现」。只有在引用持牌通讯社时，才点名「法新社查证」。
  - 链接：https://news.cnr.cn/sq/20260321/t20260321_527558123.shtml
- **腾讯「较真/核真录」类核查稿**：用「外网」「外文网站」「AI 图片识别工具」等说法，平台名照写。不过这些是持证新闻机构的稿件。
  - 链接：https://view.inews.qq.com/a/20240303A084E000
- **何同学、不白吃**：没找到可引用的公开字幕文本，下面是**推断**。头部科普号口播大多说「有网友」「网上流传」「国外有个团队」「某检测工具」，平台 logo 一般裁掉或打码，原始链接放在简介或评论区。

**结论：** 非新闻号用下面这套最稳。不点媒体名和平台名，也不用「外网」「外媒」。

| 原来的说法 | 改成 |
|---|---|
| BBC 等媒体 | 核查机构 / 专业机构 |
| X、Instagram 等平台 | 网上流传 / 网友 / 账号 |
| Hive、OpenAI | 检测工具 / AI 工具 |
| Grok | AI |
| 搬运号 | 转发的账号 |

「海外社交平台」是央视用过的说法，必要时可以用，本片没用。
