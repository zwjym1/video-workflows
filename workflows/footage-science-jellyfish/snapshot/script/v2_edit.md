# v2 深编（字幕 | 配音文本）
天都黑了，这只“水母”为什么还在发光？
它不是UFO，是一枚火箭。
10月23号傍晚，长征六号改从太原起飞，
北京、山西、山东都有人拍到了它。
秘密在高度。
那会儿太阳落山半个多小时，地面已经在地球的影子里。
可几十到上百公里的高空，还晒着太阳。
火箭一冲出影子，就像被追光灯打亮了。
那为什么是水母的形状？
低空空气稠，尾焰被压成细细一条。
越往上越稀，到一百公里，气压不到地面的百万分之一。
尾气一出喷口就往四周猛地胀开，撑成一把大伞。
里面的水汽在零下八十多度，直接冻成冰晶，
冰晶一散射阳光，伞盖和触须就一起亮了。
想看到它，得同时凑齐三样：
清晨或傍晚发射，高空没大风，头顶没厚云。
少一样，就很难看到这么完整的水母。
那天傍晚，三样全凑齐了。
