# T09 对标拆解：小白debug《DeepInfer是什么？》（7700231617540853026）
数据：3840×2160 30fps，679.3s；逐字稿约 6200 字，语速约 9.1 字/秒，偏快。
方法：ffmpeg 降采样后做场景检测（阈值 0.2），每 10 秒取一帧拼图，前 36 秒逐秒拼图，用 RMS 做响度分析。
关键帧拼图：keyframes_hook_0-36s.jpg、keyframes_overview_1.jpg（0–6 分钟）、keyframes_overview_2.jpg（6–11 分钟）、keyframes_ending.jpg

## 1. 开场钩子
- **前 3 秒**：口播直接抛题“DeepInfer是什么？它为什么能让DeepSeek跑得更快更省？”。画面上，标题牌加问号方块，鲸鱼像素图标游进来，第 2 秒就出现 GPU 卡阵。没有片头，也没有真人。
- **3–28 秒**：
  - 先用人设梗拉近距离：“我以为梁叔只是想上教科书……其实想上历史书”。画面配像素老奶奶/西装小人、教科书、历史书。
  - 接着用“天阶功法”卷轴把开源说成武侠秘籍。
  - 再砸两个硬数字：一天 155 万亿 Token；按波谷价，每卡每小时 $37/38。画面上有机柜、数字滚动和折线图。
  - 最后一句吐槽：“真不把我们当外人”。
- **28–35 秒**：连抛三问（是什么、原理、为什么性价比拉满），画面是标题牌加进度条。
- **35 秒**：求赞关（“看之前你点赞了吗？关注了吗？谢谢！”），画面是老奶奶加点赞图标。
- 公式：**问题式标题 → 人设梗 → 武侠/网络梗 → 硬数字 ×2 → 三连问 → 求赞关**，全程约 37 秒。

规律：
- **每章标题都是“X 是什么？”**，章末都用 **“这种……就是所谓的 X”** 把术语落地。

- 先拆零件，再总装（⑧），最后跑一遍流程（⑨）。
- 正片约 85%，钩子 6%，结尾 3%。

## 3. 画面类型占比（按 68 张 10 秒抽帧目测）
- **真人出镜：0%**。录屏：约 0%，只有 1:50 出现一个 Claude Code/Codex 的窗口示意，也是像素重绘。
- **像素风 2D 动画信息图：约 95%**。
  - 人物：梁叔像素小人、西装小人、熊/老奶奶式吉祥物。
  - 道具：GPU、机柜、神经网络方块、Token 方块“猫/爱/吃/鱼”，流水线箭头。
- 深色星空“STAGE N”章节卡：约 3%，出现在 1:40、4:00、5:38 附近，金色像素字。
- 图表和数字（折线、价格、进度条）穿插在动画里，约 10% 的帧有。
- 代码：基本没有，不出现真实代码。
- 场景检测只有 **48 个硬切，平均 14 秒一次**。其余变化全靠同一画布上元素的生长、移动和高亮。镜头是连续搭积木式的，不是快切。

## 4. 字幕与 UI
- **底部字幕**：深色描边圆角像素框，白字，关键词用**黄/橙色**高亮（例如“这种把**prefill**和**decode**”）。
  - 按语义短语切，每条 4–12 字，比“一句一字幕”更碎。
  - 位置居中，离底部约 8%。
- **画面上的术语标签**：黑底白字像素标签（权重、结果、第一层、KV cache）。
- **常驻 HUD**：右上角“❤❤❤ ▪×05 小白debug”游戏状态栏，×NN 随着讲解推进递增（实测 2:30 时是 ×05，4:00 时是 ×09），像通关计数。
  - 顶部有一条细绿色**进度条**，指示全片进度。
  - 四角有像素取景框角标。
- 每章开头左上角有一个“底层解析？+ 章节名”的小牌子。
- 字体：像素/点阵中文字体，配等宽英文。

## 5. 配色
- 主背景是**米白纸色 #F6F0E2**，带极淡点阵网格。
- 深色章节背景 #1E1B24 / #2B2735，配星点。
- 强调色：橙 #E07A3A（prefill、箭头）、青绿 #2E8F82（decode）、金黄 #F2C14E（Token 方块、高亮字），少量浅蓝和紫色给网络层分色。
- 整体是低饱和的复古像素游戏风。也有观众嫌“背景太亮”。

## 6. BGM 与音效
- 全片平均 -17 dB，峰值 -0.5 dB。
- 句间停顿最低到约 -48~-53 dB。说明**没有持续铺底的响亮 BGM**，可能完全没有，也可能是极低音量的铺底；靠数据无法区分，需要人耳确认。
- 音效：元素出场时疑似有像素提示音，需要人耳确认。
- 这一节是盲区，我没法听，结论只到“口播为主，音乐不抢”。

## 7. 切镜频率

- 画面内的动作（元素进出、高亮）大约每 2–4 秒一次，跟着口播的名词走：说到什么，什么就出现。

## 11. 评论（一级 108 条）
- **买账点**：
  - 画风/动画精致：约 12 条在问“用什么做的、什么插件、什么模型”，有人说“这视频是 Claude 做的”。
  - 讲得清楚：“学到了”“清晰易懂”。
  - 干货可收藏：“看完了点赞收藏”“请假一天研究”。
  - 梁叔/国产开源的情绪：“已经上历史书了”。
- **痛点**：
  - 太硬听不懂，约 15 条（“天书”“听懂了又没听懂”）。
  - 多条 @豆包 让它总结，说明信息密度超出了观众的承受力。
- **想看的**：
  - 更多 AI infra。
  - 拿 vLLM 对比着讲（“比如上个视频 vLLM 里讲的 engine core 对应哪个”，说明他做过 vLLM 那期）。
  - 三维重建。
  - 本地部署能不能用。
  - 想学做视频的方法。
- **专业观众纠错**：
  - 前缀缓存和 KV cache 混在一起讲了。
  - PD 编排的层次不对。
  - 神经网络图里权重应该画在边上，不是节点上。
  
  说明有一批行业观众在盯细节，**事实准确是硬要求**。
- 思考题收到不少高质量回答，留问题确实能带动评论。我们按规矩不在口播里要求评论。
