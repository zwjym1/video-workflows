# T09 模仿方案：对标小白debug

## 核心公式
**“X是什么？”问句标题 → 37 秒钩子（人设梗 + 网络梗 + 两个硬数字 + 三连问）→ 按“X是什么？→ 生活类比 → 就是所谓的X”拆 6–8 个零件 → 总装回答“X到底是什么/能不能用” → 用一个完整请求跑一遍流程 → 留一道思考题收尾。**
画面全程用米白像素风信息图在同一块画布上搭积木。说到哪个名词，哪个元素就出现。
时长 8–11 分钟，横屏 4K。

## 照抄清单（直接模仿，不自创）
1. 标题格式：`系列名｜X是什么？` + 副标题“N分钟速通X”。用问句，钉在新发布或热门框架上。
2. 钩子结构和时长照抄（约 35 秒），包括连抛三问。
3. 每章标题牌“X是什么？”，章末一句“这种……就是所谓的X”。
4. 先拆零件 → 总装 → 完整请求流程走一遍，三段式照搬。
5. 视觉：
   - 米白 #F6F0E2 加点阵背景，深色星空“STAGE N”章节卡。
   - 橙/青绿/金黄三色编码，像素字体。
   - 四角取景框、顶部进度条、右上角 HUD 计数（每落地一个术语就 +1）。
   - 底部短语字幕，关键词变色。
6. 同一画布搭积木，硬切约 14 秒一次，画面内每 2–4 秒有一个元素动作，跟着口播的名词出现。
7. 用 Token 方块“猫/爱/吃/鱼”这类可爱实例贯穿全片。可以换成自己的实例，但形式照抄。
8. 结尾：“现在大家懂了吗？”→ 留思考题 → 固定口号 → 下期见。
9. 语速快，信息密集。建议比他慢一点（约 7 字/秒），因为“听不懂”是他评论区的第一痛点。

## 做不到的地方和替代做法
| 对标有的 | 用户的情况 | 替代 |
|---|---|---|
| 前字节 AI 算法、出过书，自带权威 | 大二软工学生 | 不冒充。用“论文原文、官方文档、源码”做权威：画面角落标出处（论文名、页码、图号）。口号改成学习者视角 |
| “梁叔”这类人设梗 | 可以用，属于公众人物梗 | 只用公开、友善的梗，不编造言论 |
| 真人出镜 | 对标里本来就**没有**真人 | 不需要替代，用像素吉祥物（自己设计，不抄他的角色） |
| 他的像素角色和 HUD 品牌 | 有版权和辨识度风险 | 照抄风格和结构，角色形象、HUD 文案、口号自己画、自己写 |
| 口播里求赞关、弹幕扣 1、评论区聊 | 用户规矩：口播不求互动 | 删掉。思考题留在画面字卡上，口播不说“评论区聊”。点赞图标只做画面装饰，不配语音 |
| 疑似 AI 辅助的高精度动画产能 | Remotion + three.js、RTX 3080 | 用 Remotion 做 2D 像素信息图组件库（方块、GPU、箭头、字幕、HUD），一期复用；three.js 只在超节点/显存这类需要立体感的镜头用 |
| 真人原声 | Fish TTS s2.1-pro-free（只用于中文抖音自媒体） | 用 Fish 配音，语速调到约 7 字/秒，术语先做读音表（vLLM 读“V-L-L-M”） |
| BGM | 对标没有明显铺底 | 照抄：口播为主，无 BGM 或极低铺底。像素提示音用免费可商用音效库 |
| 他已经有 45 万粉的信任 | 新号 | 事实零误差。他评论区有人在纠错，我们每个数字都标出处 |

## 制作流水线
逐字稿（审）→ 读音表 → Fish 配音 → 按句对齐时间轴 → 镜头表 → 关键帧静帧（审）→ Remotion 渲染 → 抽帧自检 → 交付。

## 第一期候选
1. **vLLM是什么？（PagedAttention）**：DeepInfer 那期评论区有人明确要“对比 vLLM 讲”。分页是操作系统课的考点，大二学生讲有身份可信度。论文数字齐全，可以逐条核实。风险：对标可能讲过 vLLM（评论提到“上个视频 vLLM”），所以我们换角度，从“操作系统分页”切入。
2. **FlashAttention是什么？**：大模型训练和推理的底层必修，“IO 感知”很适合做像素动画（显存搬运）。缺点是更硬，评论区“听不懂”的痛点会被放大。
3. **MCP是什么？**：AI Agent 热词，对标标签里也有 AIAgent，受众面更广。缺点是偏协议和概念，“硬核速通”的感觉弱，收藏率可能不如前两个。

**选定：1。** 事实已对照 arXiv:2309.06180 原文核实（20.4–38.2%、800KB/Token、1.6GB/请求、权重约 65%、KV 约 30%、块大小 16、37.6–55.2%、20–26%、2–4 倍、8.5K Python + 2K C++/CUDA）。
