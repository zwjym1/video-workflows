## 3. 文案模板（迁移层）
- **钩子公式**：`X是什么？为什么能让Y更快/更省？` + `你是一个程序员，想……` 痛点场景 + 一个技术圈梗 + 1–2 个硬数字（带来源）+ `那么问题就来了，……？……？……？`
- **章节句式**：
  1. `X是什么？`
  2. `我们知道……`（拉回前文）
  3. 痛点：`但……就会……`
  4. 类比：数据库、仓库、页表、木桶
  5. 解法：`那就……`
  6. 落地：`这种……的……，就是所谓的X。`
  7. 可选实操：`在 vLLM 启动参数里加 --xxx 就能打开`
- **术语讲法**：先给生活类比，再给真名，真名只在章末落地一次；数字跟在机制后面，不放在前面。
- **口头禅**：
  - “那么问题就来了”约 3 次/期
  - “我们知道”约 5 次
  - “就是所谓的”15 次以上
  - “好啦，到这里”出现在总装处
- **节奏**：8–9 字/秒，句子很短，中间几乎不停顿。
  - 我们按 7–7.5 字/秒做，对冲评论区的“听不懂”。
  - 钩子 5–10%，零件章 60–65%，总装 + 落地 15%，完整流程 12–15%，结尾 3%。

## 4. 画面规格（迁移层）
- 画布：米白点阵 `#F6F0E2`；深色场景 `#1E1B25`；终端窗口深底，等宽字体。
- 每章章节卡，二选一：
  - 深色星空加金字“STAGE N”
  - 左上角牌子“底层解析？ + 章节名”
- 镜头逻辑：一个镜头约 12–14 秒，是一块画布；口播每说到一个新名词，2–4 秒内就有一个元素弹入、高亮或连线。
- 元素出场：位移加回弹，约 6–8 帧；高亮时颜色闪一下；数字用滚动计数。（这是看抽帧拼图得出的印象，没有逐帧量化缓动曲线，做原型前需要再测。）
- 实例：用 Token 方块（汉字 + 色块）贯穿全片，例如“猫/爱/吃/鱼”“大/模/型/生/成/文/字”。
- 吉祥物：像素小人，在钩子、求赞、结尾出场。**我们自己画，不用他的老奶奶或熊。**
- 组件尺寸见 `PIXEL_COMPONENTS.md`。

## 5. 素材自制边界
- **照抄**：风格、结构、句式、配色体系。
- **不照抄**：角色形象、HUD 文字（“小白debug”）、口号（“聚焦一切可能影响人类历史进程的技术”）、“以我为准”这类人设句。
