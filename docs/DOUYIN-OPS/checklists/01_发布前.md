# 01 发布前清单（每条视频）
## 内容
- [ ] 这条要测的 1 个变量是：______
- [ ] 第 1 句/第 1 个画面在 2 秒内抓人，没有“大家好我是”
- [ ] 前 5 秒说清“讲什么 + 为什么值得看”
- [ ] 每 5–8 秒有新信息或画面变化
- [ ] 结尾有一个引导评论的问题
- [ ] 时长：科普 45–75 秒（中视频版 ≥61 秒）
- [ ] 事实核对：数字、名称、读音都核过
## 格式
- [ ] 竖屏 1080×1920（横屏只用于中视频版）
- [ ] 字幕不被右侧按钮和底部文字挡住
- [ ] 画面角落有“本视频含AI生成内容”
- [ ] 真实素材标注来源，自己的解说/动画占主体
- [ ] 音乐：抖音曲库内或确认可商用
## 包装
- [ ] 标题前 8 字有核心关键词
- [ ] 封面大字 ≤10 字，用系列模板
- [ ] 话题 3–5 个：大词 + 精准词 + 系列词
- [ ] 想好置顶评论的内容
