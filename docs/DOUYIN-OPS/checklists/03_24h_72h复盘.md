# 03 发布后复盘清单
## 24 小时（快速看）
- [ ] 播放量、2 秒跳出率、5 秒完播率
- [ ] 有没有被限流/违规提示（创作者服务中心消息）
- [ ] AI 标识是否正确显示
- [ ] 回复新评论，把好问题收进选题库
- [ ] 明显比平时好？→ 标记为 DOU+ 候选（前 30 天不投）
## 72 小时（正式复盘，填 04 模板）
- [ ] 完播率、平均播放时长、完播率曲线掉人的秒数
- [ ] 点赞/评论/收藏/分享率，涨粉数
- [ ] 流量来源：推荐 / 搜索 / 主页 / 合集
- [ ] 按规则判断：
  - 2 秒跳出高 → 改开头
  - 5 秒完播低 → 前 5 秒信息不清
  - 中段掉人 → 删水分/加转折
  - 完播高不涨粉 → 补关注理由/系列感
  - 搜索来源高 → 同类词继续做
