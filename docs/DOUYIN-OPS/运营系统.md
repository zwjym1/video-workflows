# 秘书丞 · 抖音运营系统 v1（2026-10-17）

> 适用：从 0 粉起步的个人号，AI + Remotion 制作。三条内容线：①浙大猫学长风科普短片 ②小学讲题 ③轻量科技热点（带真实素材，如 Tesla Roadster）。
> 写法：每节都是“结论 → 要做的事（勾选）→ 来源”。**标【经验】的是从业者经验，不是平台官方规则；标【官方】的有官方/政府出处。** 文中不编造数据，凡是数字都给出处。
> 配套清单在 `checklists/` 目录。

## 0. 一页看懂（先读这个）

1. **一个号只做一件事被人记住。** 主线选“科普”（科普短片 + 科技热点放一起，统一叫“讲清楚一个科技/科学问题”），小学讲题建议**另开第二个号**（受众是家长/小学生，跟科技科普人群不重合，混发会让推荐系统认不清你给谁看）。
2. **抖音主推竖屏 9:16。** 现在 B 站的 16:9 横版不要直接搬：要么重排成竖屏版，要么只在想进“中视频计划”时发 ≥1 分钟的横屏原创。
3. **AI 内容必须主动打标。** 2025-09-01 起国家《人工智能生成合成内容标识办法》施行，抖音要求主动添加“内容由AI生成”标识；2026 年起发布时必须从“必选标签”里选一项（我们选“含有AI生成内容”）。【官方】
4. **新号前 20–30 条是“测试期”，不是“冲爆款期”。** 每条只测一个变量（选题 / 开头 / 封面），发布 72 小时后复盘。
5. **看数顺序：** 2 秒跳出 → 5 秒完播 → 完播率/平均播放时长 → 点赞/评论/收藏/分享 → 涨粉。哪一层掉得最狠就先改哪一层。
6. **钱的事往后放：** 500 有效粉开视频带货/橱窗，1000 粉能接星图部分任务，中视频计划不看粉丝数，看 3 条 ≥1 分钟横屏原创 + 合计 17000 播放。【官方/媒体报道】

## 1. 定位与赛道选择

**结论**
- 抖音 2025 年“砥砺计划”明确把**自然科普、前沿科技、人文社科、名校名课**列为扶持方向，投入专项流量。我们的科普/科技线正好落在里面。（来源：钛媒体 [S6]）
- 科普账号能稳定涨粉靠“选题好 + 内容 70–80 分”，爆款更看选题。【经验，来源 [S8]】
- 抖音比 B 站更依赖爆款，同一批知识博主在抖音的点赞常常只有几百到几千，个别爆款才破百万。（来源 [S6]）→ 心态上接受“大部分视频数据平平”。

**定位一句话模板**：`我是【秘书丞】，用【3D/动画 + 1 分钟】讲清楚【一个你刷到过但没搞懂的科技/科学问题】。`

**要做的事**
- [ ] 确定主号 = 科普 + 科技热点（同一人群：好奇心强的学生/年轻人）
- [ ] 小学讲题：开第二个号，或暂缓到主号过 1000 粉后再开（由 wj z 决定）
- [ ] 用巨量算数 / 抖音热点宝找 5 个“低粉爆款”同类账号做对标，记录在 `对标账号.md`（看视频 V7）
- [ ] 每条线固定一个“系列名”，后面建合集用（例：“一分钟看懂黑科技”“离谱物理”）

## 2. 账号搭建（名字 / 头像 / 简介 / 企业号还是个人号）

**结论**
- 抖音官方《知识作者成长手册》建议：名字、头像、简介要让人一眼看出你懂什么、关注你能得到什么；坚持垂直、做系列。（来源 [S5]，飞书文档对外版）
- **个人号 vs 企业号（蓝V）**：我们是个人学生创作者、不卖货、不做本地商家，**用个人号**。蓝V 需企业主体认证、偏营销工具，对科普新号没有推荐上的特权【经验】。以后有公司主体再说。
- 可申请抖音的**职业/身份认证**（如在校学生、科普作者）来增加可信度，但非必须。

**要做的事**（详见 `checklists/00_账号搭建.md`）
- [ ] 名字：`秘书丞` + 可选后缀（如“秘书丞讲科技”），好记、能搜
- [ ] 头像：统一的卡通/IP 形象（与视频里的形象一致），小图也认得清
- [ ] 简介 3 行：我做什么 / 更新节奏 / 系列入口。不要放微信号、外链（营销导流易限流）
- [ ] 背景图：写系列名
- [ ] 绑定手机号、实名认证；打开“作品同步西瓜/头条”（为中视频计划做准备）

## 3. 养号与冷启动：迷思 vs 事实

| 说法 | 判断 | 依据 |
|---|---|---|
| “新号要先养号 3–7 天刷同类视频才能发” | **部分有用，别迷信。** 推荐系统用你的行为和内容特征做匹配（双塔召回），刷同类内容能帮系统理解你，但真正决定推荐的是作品本身的用户反馈 | 抖音官方算法说明 [S1] |
| “一天发 10 条快速起号” | **错。** 低质量批量发会被当成低质创作者 | 从业者经验 [S9]；中视频计划也明确排除“简易加工、创作程度低”的内容 [S3] |
| “有固定的 200/500/3000 播放流量池” | **只能当比喻。** 官方讲的是“召回 → 多轮排序打分 → 打散/多样性/随机扰动”，没有公布固定池子大小 | [S1] |
| “点赞、收藏、转发、评论会影响推荐” | **对。** 官方明确这些行为是排序打分依据 | [S1] |
| “删视频重发能救” | **别这么做。** 删了会影响账号历史，中视频计划还要求作品不可删除 | [S3] |
| “不同时间推荐的内容不一样” | **对。** 官方叫“兴趣时钟” | [S1] |

## 4. 推荐算法怎么看我们的视频（实操版）

官方原理（[S1] trust.douyin.com/algorithm）：**召回**（用户向量 × 内容向量距离）→ **排序**（Wide&Deep 等模型，按点赞/收藏/转发/评论等行为打分）→ **打散与随机扰动**（避免推荐单一）。

翻译成创作动作：
- **前 2 秒**：决定别人划不划走（“2 秒跳出率”）。开场直接给画面冲击或问题，不要“大家好我是…”。
- **前 5 秒**：“5 秒完播率”。前 5 秒要把“这条讲什么、为什么值得看”说完。
- **全片**：完播率 / 平均播放时长。科普短片控制在 45–75 秒，每 5–8 秒一个新信息点【经验，[S10]】。
- **结尾**：留问题引导评论（例“你觉得它能量产吗？”），引导收藏（“下次被问到就发这条”）。
- **垂直**：一直发同类内容，召回时更容易找准人群。

数据在哪看：`抖音 App → 我 → 右上角三道杠 → 创作者服务中心 → 数据中心 → 作品数据`，逐条看完播率、平均播放时长、2 秒跳出率、5 秒完播率、涨粉。发布约 72 小时后复盘较稳。【经验 [S11]】

## 5. 发布频率与时间

- **频率**：前 30 天每周 3–4 条（质量优先，AI 流程能稳定产出的量）；稳定后每周 5 条。不追“一天几条”。【经验】
- **时间**：常见建议是午间 12–14 点、晚间 18–20 点、21–23 点【经验 [S12]】。**我们的做法**：前 4 周把三个时段各轮流测，自己的数据说了算（看“粉丝活跃时间”）。
- **固定节奏比时间点更重要**：例如每周二、四、六 19:00。

## 6. 标题、封面、话题（含抖音搜索）

- **标题**：前 8 个字放核心搜索词（如“特斯拉Roadster”“为什么飞机…”）；一句话说出悬念或结论。【经验 [S13]】
- **封面**：竖屏 3:4/9:16 都能看清；大字 ≤10 字；同系列统一模板，主页一排看起来整齐。
- **话题**：3–5 个 = 1 个大词（#科普）+ 1–2 个精准词（#特斯拉）+ 1 个系列词（#一分钟看懂黑科技）。【经验 [S13]】
- **字幕和口播里也要自然出现关键词**：抖音搜索会匹配字幕/口播内容【经验 [S13]】。
- **找词**：抖音搜索框下拉词 + 巨量算数关键词热度（看视频 V8、V12）。

## 7. 横屏还是竖屏？合集怎么用？

- **默认竖屏 9:16**：手机全屏，点赞评论按钮不挡画面，互动更友好。横屏适合需要大量画面细节或长讲解。【经验 [S14]】
- **我们的三条线**：
  - 科普短片：竖屏（Remotion 直接出 1080×1920 版）
  - 科技热点（Roadster 这类）：**做竖屏重剪版**发抖音；16:9 原版留给 B 站。若想冲中视频计划，可另发 ≥1 分钟的横屏原创版。
  - 小学讲题：竖屏，板书放中间偏上，下方 1/4 留给字幕和按钮
- **合集**：每个系列建一个合集，名字含关键词。合集把同类内容串起来，观众看完一条会顺着往下看，搜索也能搜到。【经验 [S13][S14]】

## 8. AI 内容标识（必须遵守）【官方】

- 国家《人工智能生成合成内容标识办法》2025-09-01 施行：AI 生成的文字、图片、音频、视频要有**显式标识**（用户看得到）+ **隐式标识**（文件元数据）。（[S2] 中国政府网）
- 抖音：发布 AI 内容需**用抖音提供的标识功能主动添加**；未主动标识的，平台检测后会补加“疑似使用了AI生成技术，请谨慎甄别”；元数据里带 AI 标识的会显示“作品含AI生成内容”。（[S4] 新华网转人民邮电报）
- 2026-05 抖音发布《抖音内容标识使用规范》：用平台 AI 特效或第三方 AI 工具生成的内容应添加“内容由AI生成”标识，并加强治理漏标、规避标识。（[S15] 中国网络视听节目服务协会）
- 2026-05 中央网信办：短视频发布必须从 6 个“必选标签”里选一个（含有虚构演绎内容 / 含有AI生成内容 / 含有营销信息 / 内容为转载 / 内容为个人观点 / 无需标注），未规范标注的会补标、纠正、教育警示。（[S16] 中央网信办）

**我们的规则**
- [ ] 用了 AI 配音（Fish 等）、AI 画面、AI 文案 → 发布时一律选“含有AI生成内容” + 打开 AI 声明
- [ ] 视频画面里也加一行小字“本视频含AI生成内容”（片头或角落），双保险
- [ ] 不把 AI 生成画面伪装成真实拍摄；不做 AI 换脸真人
- [ ] 不去除 AI 工具写入的元数据

## 9. 原创与搬运风险（真实发布会素材）

- 中视频计划明确：只有**声明原创**的作品才有收益；“基于一定素材简易加工、创作程度较低”的内容不能加入。（[S3] 西瓜创作平台规则）
- 发布会/官方宣传片属于他人版权素材。我们的原则【经验，结合 [S3]】：
  - [ ] 真实素材只作“引用”：单段尽量短，整片里**自己的解说 + 自己做的动画/图示占主体**
  - [ ] 画面上标注来源（如“画面来源：Tesla 官方”）
  - [ ] 含大量他人素材的视频**不要勾“原创”**，或选“内容为转载/个人观点”中更合适的标签
  - [ ] 不直接搬运整段发布会；不用别人的二创视频当素材
  - [ ] BGM 只在抖音内选曲库音乐，或用确认可商用的音乐（B 站学习用的 NCS 等，发抖音前确认授权）

## 10. DOU+：什么时候值得投

- **前 30 天原则上不投**：先用自然流量判断内容。
- 值得试投 50–100 元的信号【经验 [S12]】：某条自然数据明显比平时好（完播、点赞率高于账号平均），想放大它。从业者常说完播约 30%+、点赞率约 3%+ 再追投，这是经验数，不是官方标准。
- 投放目标选“点赞评论”或“粉丝增长”，定向选“相似达人”（填对标账号），时长 2–24 小时，小额多次，数据差就停。【经验 [S12]】
- 数据本来就差的视频，投 DOU+ 救不回来。

## 11. 数据复盘：创作者服务中心 + 巨量算数

- 单条看：2 秒跳出、5 秒完播、完播率、平均播放时长、互动率、涨粉、流量来源（推荐/搜索/主页）。
- 读法【经验 [S11]】：
  - 2 秒跳出高 → 改开头画面和第一句话
  - 5 秒完播低 → 前 5 秒没讲清“讲什么”
  - 中段流失（看“完播率曲线”，视频 V11）→ 删水分、加转折
  - 完播高但不涨粉 → 主页/系列不清楚，结尾没给关注理由
  - 搜索来源占比高 → 这类词继续做，建合集
- 巨量算数（trendinsight.oceanengine.com）：看关键词热度、相关词、人群画像，选题前查一下。

## 15. 与 B 站联动

- 同一题材做两版：**B 站 16:9 完整版**（更长、更深）+ **抖音 9:16 精简版**（更快、钩子更强）。
- 抖音简介 / 评论不放 B 站链接（导流风险）【经验】，可在 B 站简介写“抖音同名：秘书丞”。
- 两边数据分开复盘：B 站看完播 + 收藏 + 弹幕，抖音看 2 秒/5 秒 + 完播。
- 同一视频两边都声明原创时，确保作者是同一人，避免被判搬运。

## 16. 前 30 天 / 90 天计划

### 第 1–30 天：测试期（目标：找到 1 个数据明显好的格式；不设粉丝 KPI）
| 周 | 做什么 | 产出 |
|---|---|---|
| 第 1 周 | 搭号（清单 00）；找 5 个对标号；建选题库 30 条；做竖屏模板（片头、字幕、封面、AI 标识角标）；正常刷同类内容、互动 | 账号就绪 + 模板 + 2 条视频 |
| 第 2 周 | 每周 3 条科普短片；测**开头**（问题式 vs 画面冲击式） | 3 条 + 复盘 |
| 第 3 周 | 3 条：加 1 条科技热点竖屏版（Roadster 重剪）；测**发布时段** | 3 条 + 复盘 |
| 第 4 周 | 4 条；测**时长**（45s vs 75s）；建第一个合集；月复盘 | 月报：哪种格式最好 |

### 第 31–90 天：放大期
| 周 | 做什么 |
|---|---|
| 5–6 | 把最好的格式做成系列，每周 4–5 条；开始做竖屏+横屏双版 |
| 7–8 | 加做 ≥1 分钟横屏原创，凑够中视频计划 3 条；对数据最好的一条试投 DOU+ 50–100 元 |
| 9–10 | 评论区点播系列；根据粉丝画像调选题；决定小学讲题是否开新号 |
| 11–12 | 季度复盘：保留前 20% 的选题类型，砍掉后 30%；达到门槛后申请中视频计划 / 开橱窗 |
