# 渲前结构检查清单（每次 render 之前过一遍，约 2 分钟）

目的：把「渲完 → 自检 → 审片官 → 返修」一轮约 17–19 分钟才能发现的结构问题，在渲染前用几秒钟拦下来。依据 EP-20261029-01 v6c–v6h 六轮返修单里反复出现的问题。

## 1. 自动闸门（必跑，不过不渲）
```bash
python3 templates/qc/structure_gate.py \
  --cuts  <工程>/design_cuts.json        # 或 sfx/cuts_v2.json（{"cuts":[[名字,秒],…]}）
  --words <成片时间轴上的字级时间 json>  # 格式 [{chars:[[字,起,止],…]},…] 或 asr.json
  --total <成片秒数> \
  [--events <推镜/贴纸/字卡事件 json>] [--json 报告.json]
```
- 退出码 0 = 通过；1 = 有 FAIL，先改再渲；2 = 输入有问题。
- 规则：H1 第一个切点必须是 0｜H2 前 10 s 镜头不短于 0.9 s（FAIL）｜H3 钩子窗口切点不落在字中间（WARN）｜H4 3–10 s 内超过 1.6 s 没有任何画面变化（WARN）｜H5 最后一镜太短、或配音比成片长（FAIL）｜H6 相邻两镜用同一素材（WARN）。
- ⚠ H3 只有在 `--words` 是**成片时间轴**上的字级时间时才可靠。EP-20261029-01 现有两份都不行：`vo/cards_timed_v4.json` 是加停顿、加片头 0.12 s 之前的配音时间（例如「十」在 cards 里是 4.32 s，成片字幕这一句 4.62 s 才出）；自检目录里的 `asr.json`（盒上 `tools/review/out/jelly_v6c/`，未入库）是成片 ASR，但字边界太粗。两者都没查出 v6c 在 4.305 s 切进「箭」字（审片官人工发现）。后续改进：让 `build_timing_v2.py`/`pause_v4.py` 输出加停顿后的字级时间（代码改动，见效率审计 P6）。H1/H2/H4/H5/H6 不依赖字级时间，照常可靠。
- 阈值可调：`--min-shot 0.9 --hook-end 10 --word-margin 0.04 --max-gap 1.6 --win 3,10`。
- 实测：v6c 切点 → FAIL H2（c04 3.610–4.305 = 0.695 s）+ WARN H4（4.30–6.19 = 1.88 s），正是审片官 v6c 返修单第 1 条；v6h 切点 → 0 FAIL。
