适用：竖屏日更两更（午 + 晚）科技科普  
上级文档：`preproduction_workflow.md` · `direction_reset_2026-10-20.md`

## 黑白结论（先看这 5 条）

1. **公开热榜只做初筛；不过抖音实地，不许定题开做。**
2. **抖音实地全部归通政使**；允知只排期协调，**不代看片**；秘书丞拿到实地包后才写口播/成片。
3. 实地三项必修：同题热门开头 0–5s 画面 + 口播原文、评论高频、相关搜索。**缺任一项 → 不得定稿口播 / 不得开渲。**
4. 日更两更：中午一条 + 晚上一条；质量不够就**空槽**，不灌水。
5. 权重：抖音热榜 **40%** / 账号匹配 **25%** / 产能 **20%** / 红线 **15%**。结构只认：现象 → 因为什么 → 一句钉死；0–3s 奇观；一句一字幕。

## 一、角色分工（谁干什么）

| 角色 | 干什么 | 不干什么 |
|---|---|---|
| **通政使** | 抖音实地采集（S1.5）：看片、抄开头原文、扒评论、抄相关搜索 → 交 `field_douyin.md` | 不定稿口播、不渲染、不替秘书丞写文案 |
| **允知** | 午/晚排期、日报提示、跨助手调度、提醒缺实地包 | **不代看片、不写 field_douyin、不定口播语气** |
| **秘书丞** | S1 热榜初筛打分 → 收实地包 → 改钩子/搜索词 → 事实表 → **先定声音再写口播** → 成片 | 无实地包时不得定稿口播/开渲；禁止万能口播壳 |
| **用户** | 过目标题/口播/预览；最终 GO | — |

一句话：**采集 = 通政使；排期 = 允知；文案成片 = 秘书丞。**

## 二、端到端流程（文字图）

```
[S0 方向闸门]
  品类=科技科普？能问「为什么/怎么/真假」？0–3s 能做出肉眼奇观？

  ↓

[S1.5 抖音实地 · 通政使 · 硬门槛 · 不可跳过]

  ↓

[S3 Go/No-Go 闸门]
  全部过才进确定槽；否则换题或空槽
  ↓

[S4 标题封面先行 → 事实表 → 口播（见《文案系统_v2》）]
  用户过目 → 配音 → 成片
  ↓

[S5 发布后 24h/72h 回填]
  2s 跳出 / 5s / 均播 / 完播 → 反哺权重与砍题清单
```

## 三、S1 热榜初筛（公开榜 · 免登录）

### 工具（抖音不登录）
- 本机：`/workspace/tools/dy_data.py hot` → CSV 快照（记抓取时间 Asia/Shanghai）
- 辅：微博热搜、B 站热门、百度热搜、Google Trends、X 官方一手

### 入选门槛（经验值，跑 4 周后按数据调）
- [ ] 抖音热搜/话题前 30，或指数「飙升」
- [ ] 能讲成「为什么 / 怎么做到 / 真的假的」（科技科普匹配）
- [ ] 时效 ≤48h，或有确定节点（发布会、发射日、挑战日）
- [ ] 跨平台 ≥2 为加分，不是硬门槛（小号靠抖音时效）

### 输出
候选表写入当日选题简报或允知日报草稿：

| # | 选题 | 榜位/热度 | 抓取时间 | 类型预判（Roadster类/资讯/辟谣/砍） | 备注 |
|---|---|---|---|---|---|

**公开榜 ≠ 定题。** 过了 S1 只进「待实地」。

## 四、S1.5 抖音实地（通政使 · 硬门槛）

### 每条候选必须交齐

| 项 | 最小合格标准 | 不合格 |
|---|---|---|
| 同题热门 | Top8–10（底线≥8）；每条写清：账号、标题、量级粗估、**0–5s 画面**、**口播原文逐句** | 「大概讲了原理」「开头挺炸」这类空总结 |
| 评论高频 | ≥5 条可引用原话或合并同类；标出「观众真问什么」 | 只写「评论很多」「有人骂假」 |
| 相关搜索 | 搜索页联想 + 看后搜，各列 ≥3 词；圈出标题可埋词 | 自己编搜索词不看页 |

### 执行
1. 通政使用模板：`field_douyin.template.md` 复制到选题目录，改名为 `field_douyin.md`
2. 看片必须实际播放 0–5s，原文照抄（可标 [听不清]）
3. 交包时通知秘书丞路径；允知只把状态从「待实地」改为「实地已交」

### 禁区
- 不二次传播血腥/灾难整段；辟谣类只记破绽，不搬运猎奇
- 不登录爬隐私；公开页/授权看片即可
- 不替秘书丞写「建议口播全文」——只交素材与观察

## 五、打分规则

总分 100，**≥70 且红线满分**才可进确定槽。

| 桶 | 权重 | 怎么打 |
|---|---|---|
| 抖音热榜位次 | **40** | 前10→40；11–20→32；21–30→24；飙升未进30→16；未核实位次→≤12 并注明 |
| 账号匹配 | **25** | 科技科普+搜索奇观（Roadster类）→25；资讯快评可讲原理→18；弱视觉纯流程→≤8（默认砍） |
| 产能 | **20** | 当日可出（已有预览/事实锁）→20；2–3h 可锁→14；>4h 或素材缺口大→≤8（宁可空槽） |
| 红线 | **15** | 全过→15；任一红线触发→**整题 0，直接砍** |

### 红线（触发即砍）
- 地缘政治立场、时政评论
- 整段假灾难 / 血腥猎奇二次传播
- 无关机型组件挂载、地点定位口播
- 未成年人、隐私、无依据贬损品牌
- 「一看二算三打」式步骤慢讲结构（数据已判死刑）

### 实地包怎么用（不替代热榜分）
- 改 **0–3s 钩子**：抄爆款开头结构，不抄原句当自己的
- 改 **搜索词**：相关搜索里选量大、能埋进标题的
- 判 **撞车**：同切口已有爆款且我们无新钉死点 → 降匹配分或换切口
- 供 **文案系统** 定「这条的声音」与评论答疑句

## 六、Go / No-Go 闸门（写稿前）

**全部勾上才 GO：**

- [ ] S1 热度门槛达标（或有明确节点）
- [ ] **field_douyin.md 三项齐全**（路径写在简报）
- [ ] 总分 ≥70 且红线 15/15
- [ ] 0–3s 钩子已用一句话说清（画面级，不是「今天讲…」）
- [ ] 标题可搜（含相关搜索选出的词）
- [ ] 核心论断能进事实表（✅ + ≥2 独立来源）——写稿前至少锁主论断
- [ ] 产能：本槽能在发布窗前出片；否则空槽

记录格式：`GO / NO-GO —— 一句理由` + 实地包路径。

## 七、日更两更与允知日报衔接

### 排期规则
| 槽 | 默认内容类型 | 状态机 |
|---|---|---|
| **午槽** | 短竖屏（≤35s）快锁题；奇观帧+一句钉死 | 待实地 → 实地已交 → 确定槽 → 用户过目 → 成片 |
| **晚槽** | 可吃已预览成品 / 稍重原理竖屏 | 同上；质量不够空槽 |

- 两槽**各自**过实地；不能「晚槽实地顶午槽」
- 允知日报里每条必须标：`实地：缺 / 已交(path) / 不适用(说明)`
- 缺实地 → 只能进「待实地」，**禁止**标「今晚必发」

### 允知该写什么（示例一行）
```
午｜DeepSeek动画｜榜#24｜待实地｜通政使补 field｜秘书丞等包后写口播
晚｜张雪水上漂｜榜#17｜实地已交(path)｜用户过v4｜秘书丞改钩渲1080
```

### 秘书丞接到日报后
1. 只对「实地已交」的题开事实表/口播
2. 发现日报把「待实地」标成确定槽 → 打回允知改状态
3. 空槽时主动写一句「空槽原因」回填，不灌水顶替

## 九、验收清单（选题采集做完没有）

通政使交包前自检：
- [ ] Top8–10（底线≥8） 每条有 0–5s 画面 + 口播**原文**
- [ ] 评论高频 ≥12（可引用原话）（原话或合并）

- [ ] 写了「对我们切口的撞车判断」一句

秘书丞开写前自检：
- [ ] 实地包路径有效且三项齐
- [ ] 打分表填完，红线未触发
- [ ] 0–3s 钩子、搜索词已按实地包修订
- [ ] 简报 Go/No-Go 已写

允知排期自检：
- [ ] 未把待实地标成确定槽
- [ ] 未代写 field 或口播
- [ ] 空槽已标明，未要求灌水

## 十、砍题默认清单（采集阶段就拒）

- 展会流程讲解、步骤编号开场
