## 构图、比例、字幕：差距不在“再多加几张板”
- R1五次板锚点合计64.00s，占全片37.4%；含18秒左右原速复看及其它收束。
- R2按已校正锚点与部分约值估板63.45s，约55.8%；不能说精确到每像素，部分边界仍±0.5s。
- 现片源状态表精确：局部板34.64s＋总板8.48s＝43.12s，占全片43.4%；排除20.4s原速后，占解说区54.6%。**已经接近R2讲解区板量，不缺板数量，缺板回答的问题。** 三者片内回放结构不一样，不能直接按总占比判优劣。
- 原尺寸取样字幕白/黄亮部连通域中位高度：R1 19秒35px/1080高，R2 51.8秒31px/960高，现片40秒27px/720高。是可见字形候选高度，不是字体设置/全片精确字高；R1有分离笔画干扰。现片33px字幕设定并不比参考相对更小，继续把字号当主因没有证据。
- 现片40秒同时有顶栏标题、攻向、小地图、侧栏两句、固定三行图例、底角免责声明、多个球员注释、底字幕。参考R2 51.8秒除品牌/小地图外，主读序只有包围关系和底字幕。我们应把固定说明从画面主层移走，放大本次关系，而非加更多HUD；R1虽点多，却只亮正在讲的局部。

## 声音：哪些真知道，哪些不能说
1. 新参考部分强切有锁定低频瞬态：47.000画面事件对46.994音频峰（领先6ms，低于250Hz能量约0.61）；21.333较弱。是否独立SFX仍可能是BGM踩点。14.133回实拍没有同等级峰；25/27画线、51包围、105–113总结均无干净独立音效证据。详见既有SFX_CUES.md，不扩写成每传必响。
2. R1已识别主床为李富贵《人生志在一博》，尾曲《passion》原速；是旧参考识别，不是R2同曲结论。R2 BGM具体曲名和独立音效母版未知；本轮没再识曲。
3. 本轮对实际AAC测ffmpeg loudnorm输入：R1 -8.52 LUFS / +1.53 dBTP，R2 -6.86 / +2.27，现片 -18.20 / -1.31。RMS各窗见JSON，现片前10秒-21.22 dBFS，尾82–98秒-22.29。**现片电平明显更保守，是实测差距；但不能把此前“无声”确定归因于此，也不能说更大声必然更好。** 参考解码真峰超0，照抄会有过载风险；新方案通过旁白动态控制＋整体约-16 LUFS、真峰≤-1.5dBTP获得稳定可听层级，不直接抬总增益追到-7 LUFS。
4. 现片SFX确实混入：15.28、30.92、46.08低顿点，31.72一次whoosh；相对旁白实测分别-16.21/-14.57/-8.52/-14.22dB。不是没学音效；改进点是电平一致性与切点功能，不再加满。BGM分离有泄漏/空频局限，没有正版干净母带，不可称声音已经一模一样。声型/听感未真人听审。
