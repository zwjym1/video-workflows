# 新参考音效核查与新片可用独立音效

对象：`/workspace/football-demo/full-phase-new-reference/` 中《战术板解析系列|2022世界杯决赛：阿根廷高效反击》（视频 ID 7697948895069900068）。分析的是已混音原轨，不是分轨母版。未做人工听感判断，模型分数不是事实。

## 结论（先看这个）

参考片**不能**被总结成「每次切换、标签、画线、包围、总结路线都有音效」。观看时码有的是近似或错位，交叉原音与实画后：

- **只有 1 类**在参考混音里站得住：部分**实拍↔战术板硬切**上，存在与画面锁定的**短促低频顿点**（最佳例：47.000s）。它也可能只是 BGM 踩点，不是已分离的独立音效层。
- 标题弹出、落点标签、14s 圈注、25s 所谓红区、27s 传球线、51s 包围、105–113s 总结连续路线：**没有**可靠的配套独立音效证据。
- 既有 T01–T12 通谱峰多数落在字内或更像 BGM，不能当成 12 个音效。

新片可用的独立文件是下面 4 条**原创合成近似音效**（不是从参考片抽段）。建议只用切点顿点作为常设，其余三条可选、且要更弱。

## 方法与限制

- 画面：对 `reference/watch_reference_h264.mp4` 做 30fps 帧差和高饱和墨量/红黄变化，并抽帧核对。
- 音频：对 `audio/reference_original.wav` 做正对数谱通量；**在视觉事件时刻 ±40–50ms 取值**。若改用 ±0.4s 内最近高峰，几乎总会撞上旁白或 BGM，不能用来「证明有音效」。
- 分类：本地 `laion/clap-htsat-unfused` zero-shot。它常把低频短促标成 kick，只作交叉，不当事实。
- ASR：`analysis/local_asr.json` 为机器转写，52–75s 有重复和错字，只用来看瞬态是否落在字内。
- 成片峰值几乎顶到 0 dBFS，旁白段 RMS 约 -9.2 至 -9.7 dBFS；短音效即使存在也被压在人声里。
- 本轮没有把 Demucs 鼓轨叫做独立音效。

详细数据：`PROBE_MEASUREMENTS.json`、`VISUAL_CHANGE_PEAKS.json`、`VISUAL_OVERLAY_AND_FLUX.json`。

## 参考片中站得住的声型（1 个）

### 硬切对齐的短促低频顿点（中高把握：有锁定瞬态；是否独立音效层仍待确认）

| 项目 | 内容 |
| --- | --- |
| 最佳例 | 视觉硬切 **47.000s**（实拍开始上板，帧差 mae≈50.5，墨量 +0.73）对齐音频峰 **46.994s**（领先 6ms） |
| 频谱 | 通量百分位 99.0；质心约 440 Hz；250 Hz 以下能量约 0.61；相对前垫 RMS 约 +2.9 dB |
| 其他交叉 | 该窗机器 ASR 未落在字内；CLAP 顶类 `football kick` 0.91（模型分，非听感定名） |
| 较弱同类 | **21.333s** 上板起始，音频 21.267s（领先 66ms），CLAP kick drum 0.71，未落在字内，通量 p95.8 |
| 不宜单独立案 | **86.867s** 硬切且通量 p99.7，但字幕/ASR 为「再看远端…」，声词重叠 |

**不是每次切换都有：** 2.667s（标题内换镜头，通量 p79）、**14.133s 回实拍（p71.5，高频百分位仅 14）**、80.000s（p88）、98.267s（p90，高频 p25）都没有同等顿点。

响度：47s 短窗 RMS 约 -7.5 dBFS，只比旁白高约 2 dB，且同样顶到 0 dBFS，说明即便有顿点也没有「压过人声」的空间。新片里这条只能作为很短、明显低于旁白的点。

## 铺轨规则

1. 只服务强视觉变化：硬切/上板、第一次关键标签、第一次关键画线或圈注。
2. 不要每次传球、每个红点、每条包围线、总结段每一段路线都铺。
3. 音效要比旁白低 **8–12 dB**，短促收尾；不要盖旁白。参考成片本身也没有把短瞬态压过人声。
4. 音效跟画面走，**不要跟 BGM 节拍对齐**。
5. 参考片多数图形是渐进画出的；新片若也是渐绘，优先不加，或只在第一条线上用一次弱 whoosh。
