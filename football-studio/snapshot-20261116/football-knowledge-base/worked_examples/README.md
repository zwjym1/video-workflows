## E01 S04

原句：球送到中圈。厄齐尔一脚转给贡多齐，贡多齐再向右路出球。中间负责中转，外侧负责接着向前送。

普通话改写：中间这一下的价值，不是多传一次。厄齐尔附近已经有蓝衣；他借贡多齐把球送到外侧，贝莱林继续往前。这样，中间的人不必自己连续带球，也能把推进交到另一条通道，再无球跟上。

允许的专业解释：一脚中转提供从中央接点到外侧推进的办法；附近压力与转边后动作支持此功能解释，但不证明原先直带必定失败。
