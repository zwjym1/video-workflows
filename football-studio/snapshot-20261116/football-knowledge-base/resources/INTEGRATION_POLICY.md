# v1资源层的导入决定

只收8个资源指针、原协议链接、原创用途/边界摘要；不打包数据/书/视频/规范全文，不运行模型，不开发RAG。专业理论不由星数证明。

- hudl/open-data：依另路实际读取的LICENSE.pdf（文末2023-09-08），须审慎对待原始数据再分发及商业利用数据/衍生分析的限制。v1不导入数据，不据其数据制作面向变现的新演示。公开署名或logo不自动解除商业限制；后续用途需核当时协议或授权。这不是法律意见。
- Metrica：根目录无LICENSE，仅README有限说明，故只留指针，不把“可公开看到”当再分发许可。
- socceraction/LaurieOnTracking/Soccermatics：可参考其方法定义，模型≠事实，代码MIT≠教材、视频或输入数据开放。
- kloppy/mplsoccer：数据标准化和画图工具，不是战术理论；其许可证不覆盖经它们读取的数据。
- SoccerNet：软件MIT不覆盖所有视频/标注；部分需审批/NDA，此次不申请或下载。

事件≠22人连续无球跟踪；360是事件冻结画面；tracking样本少且可能有遮挡/识别误差。xT/VAEP/pitch-control是模型假设下的估计，不借其名补造画外跑动或“真实视野”。
